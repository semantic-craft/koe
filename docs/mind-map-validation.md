# 思维导图交付与验证

对应 #28，基于已交付 #27 的结构化纪要。入口为“摘要与分析 → 结构化纪要 → 思维导图”。导图由已有纪要直接映射，查看、缩放、折叠和导出不调用模型。

## 行为与边界

- 固定 GraphView 1.5.1，只复用其树布局算法。节点保留分类与事项身份，点击事项展示完整原文依据，未提供可靠时间戳时不伪造时间跳转。
- 提供拖动、放大/缩小、适应画布、分类折叠、全部展开以及可访问的层级文本视图。纪要编辑或重新生成后按结果版本更新；旧转写的过期提示会传递到导图。
- PNG 导出从完整纪要另建离屏画布，包含折叠的分支，不截取屏幕；包含录音标题、模型和纪要版本信息。内存保护上限为 1600 万像素、最长边 8192 像素；为保证文字可读，缩放比例低于 0.65 时明确拒绝并建议导出文字纪要，不丢弃节点。
- 超过 300 个节点时仍保留全部内容，界面转为完整层级文本，明确提示不提供该大图 PNG。不是鱼骨图、统计图、同步或跨录音问答。

## 自动化验证

- 265 项全量回归与静态分析通过。
- 390/1100 宽度验证折叠/展开、原文回溯、纪要编辑后刷新，并核对浏览过程没有新增模型调用。
- 布局测试保留全部事项及唯一身份、节点不重叠；80 个长中文议题测试不截断内容。
- 离屏生成真实 PNG 并解码检查完整画布尺寸，验证导出不依赖当前视口。
