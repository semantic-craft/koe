# 结构化纪要交付与验证

对应 #27，承接已合并的 #24。用户批准继续使用千问、已有短录音；双端同步、跨录音问答不在本次范围。

## 交付行为

录音详情 → 摘要与分析 → 结构化纪要。用户手动生成通用会议纪要，包含概览、议题、决策、待办、未决问题；字段校验通过后才保存。待办包含负责人、期限与原文编号，未提及不补造。来源按钮展示实际转写片段，当前以来源段为单位，不伪造精确时间戳。

复用现有千问服务和付费任务恢复机制，结果独立保存在 minutes 槽位；与摘要、自定义分析互不覆盖。字段可编辑，编辑时间和原始来源保留；重新生成先确认，失败保留原结果。导出 Markdown，iPhone 使用系统分享。

模板采用自 Meetily 与 Ownscribe 的适合部分；固定参考版本及 MIT 许可见 THIRD_PARTY_NOTICES.md。没有引入二者的运行时、完整产品或额外模型。
