# Koe iPhone 无人值守验收清单（Codex + iPhone Use）

本机 Codex 读这份清单，自己完成全部验收，过程中不找人：用 [iPhone Use](https://github.com/zhongerxin/iPhone-use) 通过 USB 操作 iPhone，用本机 shell 生成测试素材、朗读台词、重启 App、录下手机外放的声音，用 Mac 的界面自动化操作 Mac 版 Koe。主流程约 45 分钟，加测约 30 分钟。做不到的项目记 `UNCOVERED` 并写明原因，不停下来等人。

## 一次性环境（第一次搭好，以后每次验收都不用人）

只在第一次需要你动手，之后保持原样即可：

1. iPhone 用数据线常接这台 Mac；iPhone Use 已安装且 `pua_ready` 返回 `ready=true`（按插件 README 的提示词让 Codex 装）。
2. 录音豆放在充电盒里、盒盖打开、接上电，摆在 Mac 扬声器旁 20 厘米内，且已和 Koe 连接过一次。
3. 给 Codex 一次性授权：「系统设置 → 隐私与安全性」里的**辅助功能**（操作 Mac 版 Koe）和**麦克风**（录下手机外放来核对声音）。
4. 每次开跑前手机是解锁状态（iPhone Use 本身也要求解锁）；第 0 步会把自动锁定改成「永不」，结束时改回。

之后每次验收，把下面这段发给 Codex 即可。


## 执行约定（给 Codex）

- **手机操作：** 读页面用 `pua_observe` / `pua_find`，点击用 `pua_tap`（优先按控件文字），输入用 `pua_type_text`，连续已知步骤用 `pua_batch`，长列表找条目用 `pua_scroll_find`，回主屏用 `pua_press_button`。
- **Mac 版 Koe：** 有 Computer Use 就用它；否则用 `osascript` 的 System Events 按辅助功能名称找按钮和开关。
- **Koe 标识：** bundle ID `com.semanticcraft.soundcore`；设备 UDID 用 `xcrun devicectl list devices` 查。
- **重启 Koe：** `xcrun devicectl device process launch --terminate-existing --device <UDID> com.semanticcraft.soundcore`，再 `pua_ready`。
- **判断播放位置：** 读播放条的当前时间和播放/暂停按钮。点击后等 3 秒再读一次：时间在前进，且起点与目标时间相差不超过 2 秒，算对上。
- **判断有没有声音（外放核对）：** 播放前在 Mac 上开始录麦克风，`ffmpeg -f avfoundation -i ":default" -t <秒数> out.wav`；结束后用 `ffmpeg -i out.wav -af silencedetect=n=-45dB:d=1 -f null -` 找出有声区间。手机外放有声的时段应与界面「播放中」的时段一致，暂停后应转为静音；30 秒的录音完整播完，有声区间总长应在 25–35 秒之间（说明速度正常、没有大段缺失）。
- **证据：** 每步至少一张截图；外放录音只保留 silencedetect 的结果，`out.wav` 用完删除。不要把配对信息、Key 等私密内容抄进结果。

# 主流程（约 45 分钟）

## 0. 准备（3 分钟）

**操作：**
1. iPhone「设置 → 显示与亮度 → 自动锁定」记下原值，改成「永不」。
2. 确认 `say -v '?'` 里有 Tingting 和 Meijia。把下面这段存成任务临时目录里的 `play-script.sh`：

   ```bash
   say -v Tingting "今天是 Koe 真机验收，第一句话。[[slnc 2500]]我们在测试录音豆的转写效果。[[slnc 2500]]"
   say -v Meijia "第三句，下午三点开会讨论预算。[[slnc 2500]]第四句，记得给王经理回电话。[[slnc 2500]]"
   say -v Tingting "第五句，这条录音大约三十秒。[[slnc 2500]]最后一句，验收结束。"
   ```

3. 在 `~/Library/Mobile Documents/com~apple~CloudDocs/Koe验收/` 生成：
   - `miaoji.txt`：飞书妙记格式文字稿，内容为 6 句台词，每句一行，例如 `[00:00] 林舟：今天是 Koe 真机验收，第一句话。`；时码每句加 5 秒，第 3、4 句的发言人写「王一」。
   - `miaoji-audio.m4a`：6 句台词用 `say -o` 生成，再用 `afconvert -f m4af -d aac` 转成 m4a，约 30 秒。
   - `too-short.m4a`：只读第 1 句，约 3 秒。
   - `long-60min.m4a`（第 19 步用）：把 6 句台词循环朗读到 60 分钟以上，转成 m4a。
4. 用 iPhone Use 打开「文件 → iCloud 云盘 → Koe验收」，等这些文件出现（最多 5 分钟）。
5. 打开 Koe，在「资料」页记下录音条数和最上面三条的标题（作为「不动旧资料」的基线）。

**通过标准：** 自动锁定为「永不」；手机「文件」里能看到 4 个文件；基线已记录。

## 1. 安装新版（5 分钟）· #15 #170 #174 #179

**操作：** 在仓库根目录跑 `./scripts/install-ios.sh --launch`（覆盖安装，不先删旧版）。`pua_ready` 后读取 Koe。

**通过标准：**
- 脚本退出码 0，App 打开后不闪退。
- 「资料」条数和三条标题与第 0 步基线一致，点开一条能看到文字。
- 「设置」里语音服务显示已配置，没有要求重填 Key。
- 记下 Koe 版本号（设置 → 关于）。

## 2. 连接录音豆（2 分钟）· #15

**操作：** 不打开飞书。Koe 首页右上角「扫描」，在列表里点录音豆。

**通过标准：** 显示「已连接 · 设备名」。若出现「短按充电仓下方按钮完成连接」，说明一次性环境里的首次连接没做，记 `BLOCKED`，跳过依赖录音豆的第 3、4、20 步，其余照做。

## 3. 录约 30 秒（3 分钟）· #15 #96 #170

**操作：**
1. 确认「设置」里「自动转写」是打开的。
2. 「设备」页「录音」区点「开始」，确认按钮变成「录音中…」。
3. 运行 `play-script.sh`，期间每 10 秒读一次录音详情，记下实时转写的句数。
4. 播完后点「暂停」，等状态从「录音中 / 正在保存」变成已保存。

**通过标准：** 录音期间实时转写陆续出现，至少 3 句；结束后保存为一条资料，没有闪退。

## 4. 取回录音（4 分钟）· #15 #71 #92

这一步验证「录音豆自己录、之后再取回」。

**操作：**
1. 点「开始」，播放前两句后在「设备」页点「断开连接」，再把剩下的台词播完。
2. 重新「扫描」并连接，点「暂停」。
3. 等自动取回；1 分钟后仍没有，就进「设备端」标签选中最新录音手动取回。
4. 记下这条资料的时长。

**通过标准：**
- 「资料」里只多出**一条**对应录音，没有重复。
- 时长与实际录音时间（约 30–40 秒）相差不超过 5 秒。
- 如果断开后录音豆也停了，或者重连后 Koe 把它当作同一次实时会话，就记 `UNCOVERED`（独立录音路径本轮没测到），继续下一步。

## 5. 转写（3 分钟）· #71 #96 #170

**操作：** 不点任何按钮，等第 4 步那条自动转写完成；再打开第 3 步那条，看最终文字。

**通过标准：**
- 第 4 步那条**自动**开始转写，只出现一次任务、一份结果。
- 两条的最终文字都包含 6 句台词里的至少 5 句（允许个别字错），不是只剩最后一句。
- 第 3、4 句被标成和其他句不同的发言人（没有区分只记观察，不判 FAIL）。

## 6. 点一句回听、校订（4 分钟）· #15 #170 #176 #177

**操作：**
1. 开始录麦克风 40 秒，在第 3 步那条的转写里点第 4 句（「记得给王经理回电话」），等它播到结尾。
2. 若有「章节」，点一个章节起点；若纪要里有「出处 [S1]」这类来源，点一个。
3. 把第 2 句里的「录音豆」改成「录音笔」并保存；把第 1 句的发言人改成「验收员」。

**通过标准：**
- 点句后播放条从该句时间开始（相差 ≤ 2 秒）并前进；外放录音里，在播放期间有声、播完后静音。
- 点章节或出处时同样从对应时间开始（没有章节或出处就记 `UNCOVERED`）。
- 改字和改发言人保存成功；出现「旧时码无法再对应」类提示属正常。

## 7. 书签（3 分钟）· #166

**操作：** 播放第 3 步那条，约第 5 秒和第 20 秒各点一次「为当前片段加书签」，第二个写批注「验收批注」。打开「书签与批注」，点第一条回听。

**通过标准：** 两次都提示「已加书签」或「已保存书签」；列表里两条时间正确；点书签后从该时间开始播放。

## 8. 收听队列（4 分钟）· #168

**操作：**

2. 打开「收听队列」，把最后一条拖到第一位，开始播放；10 秒后跳到下一条。
3. 对正在播放的那条选择移除。

**通过标准：**
- 三条都提示「已加入收听队列」；顺序与拖动后一致。
- 跳过后播放的是队列里的下一份。
- 移除当前项时弹出「移除当前收听项？」并给出选择；选完后的提示与实际播放状态一致。

## 14. 归档到 Mac（5 分钟）· #174

前提：iPhone 和 Mac 在同一 Wi‑Fi、同一 Apple 账号（通用剪贴板把 M1 复制的内容同步到手机）。

**操作：**
1. 手机 Koe「设置 → Mac 原件归档 → 配对 Mac」，在输入框长按选「粘贴」后确认；不要读出输入框内容。弹出「本地网络」权限就点「允许」。
2. 点「归档现有资料」，等第 3 步那条进入传输。
3. 在 Mac 上 `osascript -e 'quit app "Koe"'`，30 秒后读手机上的归档状态；再 `open -a Koe` 等 1 分钟。

**通过标准：**
- 显示「已配对 Mac」；资料状态依次出现传输中、校验中、已校验归档。
- Mac 退出期间手机显示等待连接或可重试，**不显示**已归档；Mac 回来后自动继续到已校验归档。
- 归档后手机上的录音仍在，能播放。
- 若粘贴后输入框是空的（通用剪贴板没同步），记 `BLOCKED` 并注明原因。

## M2. Mac 重置配对（2 分钟）· #174

**通过标准：** 重置后手机断开；旧信息配对失败；Mac 已归档的录音还在；新信息能重新配对。

# 加测（约 30 分钟，主流程之后继续跑）

## 15. 读屏标签（4 分钟）· #15 #166 #168 #177 #178

VoiceOver 读的就是控件树里的名称，所以直接检查控件树。

## 17. 主题汇总（6 分钟，模型调用 ≤ 4 次）· #97

## 17a. 主题笔记编辑与过期（5 分钟，模型调用 ≤ 1 次）· #51 #76

**操作：**
1. 打开第 17 步「验收书」里那条录音的主题笔记，点「编辑」，改概要、一条摘录及其页码、一条评论、一条疑问/联想/待查（有哪项改哪项），保存；再打开第 12 步「验收主题」那条的思考笔记，改观点、理由、待办和结论（有哪项改哪项），保存。
2. 从多任务界面上划杀掉 Koe，重新打开，回到这两条笔记。
3. 回到「验收书」那条录音，校订转写里的一句并保存，再打开它的主题笔记；等 20 秒。
4. 点「重生成」，看到覆盖确认先选取消；再点一次「重生成」并确认。

**通过标准：** 第 2 步重开后两条笔记的所有修改都在，来源编号还能点回原句；第 3 步出现「原文、所属主题或模板已变化，当前笔记可能已过期」，等待期间笔记内容不变、没有自动重新生成；第 4 步取消不调用模型，确认后才重新生成（这一步算 1 次模型调用）。读书笔记显示的模板为「读书笔记」，思考笔记为「思考笔记」（复制笔记后粘贴可见「模板：读书笔记 v1」）。
