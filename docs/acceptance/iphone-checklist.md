# Koe iPhone 验收清单（一次走完，约 45 分钟）

把所有「需要真机」工单合成一趟，按平常用 App 的顺序排好。每一步只看三件事：**做什么**、**应该看到什么**、**结果**。看到的和写的一样就勾 ✅，不一样就勾 ❌ 并用一句话写下你看到的（截图更好）。不用懂技术，也不用一次做完；中途停下，下次从没勾的那步接着做。

覆盖工单：[#15](https://github.com/semantic-craft/koe/issues/15)、[#16](https://github.com/semantic-craft/koe/issues/16)、[#71](https://github.com/semantic-craft/koe/issues/71)、[#92](https://github.com/semantic-craft/koe/issues/92)、[#95](https://github.com/semantic-craft/koe/issues/95)、[#96](https://github.com/semantic-craft/koe/issues/96)、[#97](https://github.com/semantic-craft/koe/issues/97)、[#166](https://github.com/semantic-craft/koe/issues/166)、[#168](https://github.com/semantic-craft/koe/issues/168)、[#170](https://github.com/semantic-craft/koe/issues/170)、[#174](https://github.com/semantic-craft/koe/issues/174)、[#176](https://github.com/semantic-craft/koe/issues/176)、[#177](https://github.com/semantic-craft/koe/issues/177)、[#178](https://github.com/semantic-craft/koe/issues/178)、[#179](https://github.com/semantic-craft/koe/issues/179)。每步标题后的 `#号` 是这一步替哪些工单作证。工单里更细的检查（VoiceOver、1 小时长录音、锁屏中断等）见文末「这次不做的」。

**做什么：** 飞书 App 不用打开。在 Koe 首页点右上角「扫描」，在弹出的列表里点你的录音豆；如提示「短按充电仓下方按钮完成连接」，照做。

**应该看到：** 顶部显示「已连接 · 设备名」。全程没用到飞书。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 3. 录 30 秒（2 分钟）· #15 #71 #170

**做什么：** 先确认「设置」里「自动转写」是打开的。然后**只按录音豆上的按键**开始录音，正常说话约 30 秒（说几句不同的话，中间换个人说一句更好），再按一下结束。

**应该看到：** 录音豆正常开始、结束；Koe 没有闪退。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 4. 取回录音（3 分钟）· #15 #71 #92

**做什么：** 回到 Koe，等它自动取回；如果过了 1 分钟还没出现，去「设备端」标签选中这条录音手动取回。记下这条录音显示的**时长**。

**应该看到：**
- 「资料」里多了**一条**新录音（不是两条）。
- 显示的时长约 30 秒，和你实际录的差不多。

时长：＿＿＿＿

## 5. 自动转写（3 分钟）· #71 #96 #170

**做什么：** 什么都不用点，等这条录音自动开始转写，直到完成。

**应该看到：**
- 自动开始转写，只转了一次（没有重复的任务或两份结果）。
- 转写完的文字是**完整的**：你说的每一句都在，不是只剩最后一句。
- 文字和你说的内容基本对得上。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 6. 点一句，从那里回听（4 分钟）· #15 #170 #176 #177

**做什么：**
1. 在转写文字里点中间的某一句。
2. 如果有「章节」或纪要里的「出处 [S1]」，点一个。
3. 改一个错字，再把某一句的发言人改成别的名字。

**应该看到：**
- 点哪句，声音就从哪句开始；声音清楚，不卡、不快、不慢。
- 点章节或出处，播放的原声和那段文字对得上。
- 改字、改发言人能保存；改完后可能提示旧时码对不上，这是正常的。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

**做什么：** 播放这条录音，在两个不同位置点「为当前片段加书签」，其中一条写一句批注。然后在「书签与批注」列表里点一条回听。

**应该看到：** 显示「已加书签」；点书签，从那个位置开始播放。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 8. 收听队列（4 分钟）· #168

**做什么：** 打开 3 条录音（含刚录的），每条点「加入收听队列」。打开「收听队列」，拖一下顺序，点播放；放一会儿后跳到下一条。

**应该看到：**
- 3 条都在队列里，顺序是你拖完的样子。
- 一条播完（或跳过）自动接下一条。
- 移除正在播的那条时，会问你怎么处理，不会乱播。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 9. 关掉 App 再打开（2 分钟）· #15 #92 #96 #166 #168 #177

**做什么：** 从屏幕底部上滑，把 Koe 彻底划掉。重新打开，打开刚才那条录音。

**应该看到：**
- 时长和第 4 步记下的**一样**，没有变长。
- 转写文字还是完整的，你改的字和发言人还在。
- 两条书签还在，点了能回听。
- 收听队列还在，顺序不变。
- 没有又开始一次新的转写。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 10. 记地点（3 分钟）· #179

**做什么：** 在这条录音的「资料信息」里点「填写地点」，填一个城市；再「修改地点」改一次；最后清除。再填一次后关掉 App 重开。

**应该看到：**
- 能填、能改、能清除；重开后地点还是你最后填的。
- 地点只到省/市/区，不出现街道或经纬度。
- 「资料信息」页能往下滑到底，看到「从 Mac 恢复原件」等按钮。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 11. 导入飞书妙记（5 分钟）· #178

**做什么：**
1. 在「资料」里用「导入文字」，选妙记导出文件。
2. 同一个文件再导入一次。
3. 在这份文字资料上选择补配原音频，选对应的录音文件；然后点一句回听。

**应该看到：**
- 第一次导入后，发生时间、发言人显示正确。
- 第二次导入**没有**多出一份。
- 配上音频后显示「已配对，可按句回听」，点句子能从那里播放。
- （可选）故意选一个很短的音频，应提示无法覆盖最后一段，文字仍能看。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 12. 导出 Markdown（3 分钟）· #95

**做什么：** 打开一个已有笔记的主题（「项目」页），点「复制主题 Markdown」；再用「分享主题 Markdown 文件」存到「文件」App，或发到 Obsidian / Notion，然后在那边打开。

**应该看到：**
- 中文正常，没有乱码；标题、笔记、日期都在。
- 里面没有 Key、音频或整段转写原文。
- 空主题也能导出，并写明没有笔记。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 13. 回收站（2 分钟）· #15 #178

**做什么：** 把一条**不重要的**录音删掉（会移到回收站）。去「回收站」看到它，点「恢复」。

**应该看到：**
- 删除时提示「已移到回收站，30 天内可恢复」。
- 回收站里能看到它和剩余天数；恢复后回到资料里，能播放。
- **不要**点「清空」或「彻底删除」。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿

## 14. 归档到 Mac（5 分钟）· #174

先做完 [附录 A](#附录-amac-上要做的) 的 A1。手机和 Mac 连同一个 Wi‑Fi。

**做什么：**
1. iPhone「设置 → Mac 原件归档 → 配对 Mac」，粘贴 Mac 上复制的配对信息。如弹出「本地网络」权限，点允许。
2. 点「归档现有资料」，或等刚录的那条自动排队。
3. 归档途中把 Mac 合上盖子一会儿，再打开。

**应该看到：**
- 显示「已配对 Mac」；资料状态依次变成传输中、校验中、已校验归档。
- Mac 合盖时手机显示等待连接，不报完成；Mac 回来后自动继续。
- 归档后**手机上的录音还在**，照常能播放。

- [ ] ✅ 通过　- [ ] ❌ 不通过：＿＿＿＿
