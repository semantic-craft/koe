# Koe iPhone 验收清单（Codex + iPhone Use 执行，约 45 分钟）

这份清单由本机 Codex 借助 [iPhone Use](https://github.com/zhongerxin/iPhone-use) 插件在真实 iPhone 上逐步执行：插件通过 USB 点击、滑动、输入、读取页面和截图；声音由 Mac 扬声器用 `say` 朗读固定台词，放在旁边的录音豆录下来，所以转写结果可以和台词逐句对照。你只需做 5 分钟准备，然后把下面的提示词发给 Codex。

覆盖工单：[#15](https://github.com/semantic-craft/koe/issues/15)、[#16](https://github.com/semantic-craft/koe/issues/16)、[#71](https://github.com/semantic-craft/koe/issues/71)、[#92](https://github.com/semantic-craft/koe/issues/92)、[#95](https://github.com/semantic-craft/koe/issues/95)、[#96](https://github.com/semantic-craft/koe/issues/96)、[#97](https://github.com/semantic-craft/koe/issues/97)、[#166](https://github.com/semantic-craft/koe/issues/166)、[#168](https://github.com/semantic-craft/koe/issues/168)、[#170](https://github.com/semantic-craft/koe/issues/170)、[#174](https://github.com/semantic-craft/koe/issues/174)、[#176](https://github.com/semantic-craft/koe/issues/176)、[#177](https://github.com/semantic-craft/koe/issues/177)、[#178](https://github.com/semantic-craft/koe/issues/178)、[#179](https://github.com/semantic-craft/koe/issues/179)。每步标题后的 `#号` 是这一步替哪些工单作证；自动化做不到的项目集中在文末「Codex 做不到、需要人的」。

## 你要做的准备（5 分钟）

1. iPhone 用数据线接到这台 Mac，解锁；「设置 → 显示与亮度 → 自动锁定」临时改成「永不」。
2. 本机 Codex 已装好 iPhone Use，且 `pua_ready` 能返回 `ready=true`（首次安装按插件 README 的提示词让 Codex 完成）。
3. 录音豆充好电、打开充电盒，放在 Mac 扬声器旁 20 厘米内；Mac 音量调到七成左右，周围保持安静。
4. 要验第 14 步（归档到 Mac）时，先做 [附录 A](#附录-amac-上需要人做的) 的 A1。
5. 把下面这段发给 Codex。

```text
请按仓库 docs/acceptance/iphone-checklist.md，用 iPhone Use 在我通过 USB 连接的 iPhone 上
从第 0 步执行到第 14 步。先读整份清单，再调用 pua_setup(action="status") 和 pua_ready，
ready=true 后打开 pua_screen 实时画面。

每步按「操作」执行，按「通过标准」用 pua_observe/pua_find 的控件文字和截图判定，
在结果表里记 PASS / FAIL / BLOCKED / UNCOVERED，FAIL 写看到的实际文字并保留截图路径。
某步卡住（找不到控件、弹出意料外的系统框）先看截图重试一次，仍不行就记 BLOCKED 继续下一步，
不要反复盲点。遇到解锁、密码、Face ID 或标为「需要人」的步骤，暂停并告诉我具体要做什么。

不要清空回收站、不要彻底删除、不要删除录音豆上的录音、不要恢复出厂；只删除本次验收新建的录音。
不要读出、打印或记录配对信息和任何 Key。全部做完后输出结果表和本次 Koe 版本号。
```

## 给 Codex 的执行约定

- **工具：** 页面读取用 `pua_observe` / `pua_find`，点击用 `pua_tap`（优先按控件文字），输入用 `pua_type_text`，连续已知步骤用 `pua_batch`，长列表找条目用 `pua_scroll_find`。Mac 端命令用本机 shell。
- **Koe 标识：** bundle ID `com.semanticcraft.soundcore`。设备 UDID 用 `xcrun devicectl list devices` 查。
- **重启 Koe：** `xcrun devicectl device process launch --terminate-existing --device <UDID> com.semanticcraft.soundcore`，再 `pua_ready` 确认。
- **判断播放：** 听不到声音，只能看界面。播放是否开始、从哪开始，以播放条的当前时间和播放/暂停按钮状态为准：点击后等 3 秒再读一次，时间在前进、且起点与所点句子的时间差不超过 2 秒即算对上。
- **记录：** 每步至少一张截图。不要把配对信息、Key、手机号等出现在截图里的私密内容抄进结果。

## 0. 准备素材（Codex 在 Mac 上做，2 分钟）

**操作：**
1. 确认 `say -v '?'` 里有 Tingting 和 Meijia。
2. 把下面这段存成 `play-script.sh`（放在任务临时目录），后面第 3、4 步用它朗读台词：

   ```bash
   say -v Tingting "今天是 Koe 真机验收，第一句话。[[slnc 2500]]我们在测试录音豆的转写效果。[[slnc 2500]]"
   say -v Meijia "第三句，下午三点开会讨论预算。[[slnc 2500]]第四句，记得给王经理回电话。[[slnc 2500]]"
   say -v Tingting "第五句，这条录音大约三十秒。[[slnc 2500]]最后一句，验收结束。"
   ```

3. 在 iCloud Drive 建 `Koe验收` 文件夹（`~/Library/Mobile Documents/com~apple~CloudDocs/Koe验收/`），放入：
   - `miaoji.txt`：飞书妙记格式的文字稿，内容为上表 6 句，每句一行，格式 `[00:00] 林舟：今天是 Koe 真机验收，第一句话。`，时码按 5 秒递增，第 3、4 句发言人写「王一」。
   - `miaoji-audio.m4a`：同样 6 句，用 `say -o` 生成后 `afconvert -f m4af -d aac` 转成 m4a，时长约 30 秒。
   - `too-short.m4a`：只朗读第 1 句（约 3 秒）。
   - 若你手上有真实妙记导出（JSON/TXT）及其录音，也一并放进来，第 11 步优先用真实文件。
4. 等 1 分钟，让 iPhone「文件 → iCloud 云盘 → Koe验收」里能看到这些文件（用 iPhone Use 打开「文件」App 确认）。

**通过标准：** 三个文件在 iPhone「文件」App 里可见。

## 1. 安装新版（5 分钟）· #15 #170 #174 #179

**操作：**
1. 安装前用 iPhone Use 打开 Koe，在「资料」页记下录音条数和最上面三条的标题；没装过就记「首次安装」。
2. 在仓库根目录跑 `./scripts/install-ios.sh --launch`（覆盖安装，不先删除旧版）。
3. `pua_ready` 后读取 Koe 首页。

**通过标准：**
- 构建和安装成功（脚本退出码 0），App 打开后不闪退。
- 「资料」条数和三条标题与安装前一致，点开其中一条能看到文字。
- 「设置」里语音服务显示已配置，没有要求重填 Key。
- 记下 Koe 版本号（设置 → 关于）。

## 2. 连接录音豆（3 分钟）· #15

**操作：** 不打开飞书。在 Koe 首页点右上角「扫描」，在列表里点录音豆。若出现「短按充电仓下方按钮完成连接」，**需要人**：请用户短按一次充电仓按钮，然后继续。

**通过标准：** 顶部或「设备」页显示「已连接 · 设备名」。

## 3. 录约 30 秒（3 分钟）· #15 #96 #170

确认「设置」里「自动转写」是打开的（副标题「连接录音时实时转写，取回独立录音后自动处理」）。

**操作：**
1. 在「设备」页「录音」区点「开始」，确认按钮变成「录音中…」。
2. 在 Mac 上运行 `play-script.sh`，等它播完（约 30 秒），期间每 10 秒读一次录音详情，记下实时转写出现的句数。
3. 点「暂停」，等状态从「录音中 / 正在保存」变为已保存。

**通过标准：**
- 录音期间实时转写陆续出现多句（至少 3 句）。
- 停止后不闪退，录音保存为一条资料。

## 4. 取回录音（4 分钟）· #15 #71 #92

这一步验「录音豆自己录、之后再取回」的路径。

**操作：**
1. 点「开始」，播放 `play-script.sh` 的前两句后，在「设备」页点「断开连接」，再把剩下的台词播完。
2. 重新「扫描」并连接录音豆，点「暂停」结束录音。
3. 等自动取回；1 分钟后仍没有，就进「设备端」标签选中最新录音手动取回。
4. 记下这条资料的时长。

**通过标准：**
- 「资料」里只多出**一条**对应录音，没有重复条目。
- 时长与实际录音时间（约 30–40 秒）相差不超过 5 秒。
- 如果断开后录音豆也停止了录音、或连接后 Koe 把它当作同一次实时会话，记 `UNCOVERED` 并在「需要人」里保留「按录音豆按键独立录音」一项。

## 5. 转写（3 分钟）· #71 #96 #170

**操作：** 不点任何按钮，等第 4 步的录音自动转写完成；再打开第 3 步那条，看最终文字。

**通过标准：**
- 第 4 步那条**自动**开始转写，只出现一次转写任务，没有两份结果。
- 两条的最终文字都包含台词 6 句里的至少 5 句（允许个别字错），不是只剩最后一句。
- 第 3 句、第 4 句被标成和其他句不同的发言人（若没有区分，记为观察，不判 FAIL）。

## 6. 点一句回听、校订（4 分钟）· #15 #170 #176 #177

**通过标准：**

- 移除当前项时弹出「移除当前收听项？」并给出选择，选完后提示与实际播放状态一致，不乱播。

## 14. 归档到 Mac（5 分钟）· #174

前提：[附录 A](#附录-amac-上需要人做的) 的 A1 已完成，iPhone 和 Mac 在同一 Wi‑Fi，用户已在 Mac 上复制配对信息（通用剪贴板会同步到 iPhone）。

**操作：**
1. Koe「设置 → Mac 原件归档 → 配对 Mac」，在输入框长按选「粘贴」后确认；不要读出或记录输入框内容。若弹出「本地网络」权限，点「允许」。
2. 点「归档现有资料」，等第 3 步那条进入传输。
3. 在 Mac 上运行 `osascript -e 'quit app "Koe"'`，30 秒后读手机上的归档状态；再 `open -a Koe` 并等 1 分钟。

**通过标准：**
- 显示「已配对 Mac」；资料状态依次出现传输中、校验中、已校验归档。
- Mac 退出期间手机显示等待连接或可重试，**不显示**已归档；Mac 回来后自动继续直到已校验归档。
- 归档后手机上的录音仍在，能播放。
