# #433 中文多人区分：声纹细化验收

## 实现与边界

原生 sherpa-onnx 使用 complete-linkage 聚类；指定人数直接 cutree_k，不看自动距离阈值。微小混合簇会占用人数，导致真实人物合并。现在先运行自动分段，从独占语音提取时长加权声纹，以 cosine >= 0.7 合并同声纹，再把混合片段分配到稳定声纹。独占语音 >= 0.8 秒训练稳定声纹；0.2–0.8 秒短答只匹配，自动模式匹配不足则保留原标签。指定人数不能由证据支持，或缺证据造成结果人数不符时，回退原生人数约束。

此方案细化最终时间段，不是完整 VBx/PLDA，也不能保证自动人数精确。只在原有后台 isolate 内处理，不改变人工改名/合并/复原流程；PCM 沿用同一个原生缓冲。原生回退会再跑一次模型，增加耗时。重新分配后的原生 silhouette confidence 不再有效，使用未知值；cohesion 的取样规则发生变化，不能用前后 cohesion 证明质量改善。

## 数据与方法

在 Mac 上运行生产 Dart runner、真实 sherpa-onnx 动态库及既有固定哈希模型，不接入云端。生产代码只见音频，不读取参考标签。评测使用双侧 250ms collar、包含重叠的 DER；越低越好。

- [AliMeeting / OpenSLR 119](https://www.openslr.org/119/)，CC BY-SA 4.0，Eval_Ali.tar.gz。R8001_M8004、R8003_M8001、R8009_M8018 远场第一声道，各前 600 秒；人工 TextGrid 转 RTTM。R8001 用于开发；另外两场在首版算法冻结后取作独立对照，本轮保守短答保护变更后再次运行，因此不能再称完全未参与开发的留出集。
- AMI ES2004a Mix-Headset 0–420 秒及原有 RTTM：英文回归对照。首版固定4人为16.52%，低于原版表现；收紧无证据合并后复测，不对该片段另调阈值。
- 官方短中文四人样例：只核对 native 路径可执行和输出，无独立 RTTM，不能作为准确率验收。

本轮用户暂无自己的至少三人十分钟会议与标注。公开真实会议的原生评测不代表三端 GUI、用户听验、姓名编辑或安装验收。

## 复现

```sh
dart tool/diarization_eval.dart --cache-dir <固定模型缓存> --ami-only \
  --audio <单声道WAV> --reference <人工RTTM> --clip-seconds 600 \
  --mode auto --output-prefix <唯一前缀>
# 指定人数使用 --mode 4 或 --mode 2；英文对照为 --clip-seconds 420。
```

模型 SHA-256：
- segmentation：`220ad67ca923bef2fa91f2390c786097bf305bceb5e261d4af67b38e938e1079`
- 3dspeaker：`aa3cfc16963a10586a9393f5035d6d6b57e98d358b347f80c2a30bf4f00ceba2`

中文实际4/4/2人。自动模式仍多3/2/1个标签，保留不确定短答后没有把结果强制凑成真实人数；这不是自动人数验收完成。指定人数的中文两段明显改善，两人会议与英文对照未退化。仅此样本范围，不能推出所有语言、人数、噪声和录音设备都改善。

原生推理耗时：中文各600秒，35.07–40.90秒；AMI420秒自动17.68秒、指定4人35.54秒（回退再跑一次）。部分测试并行运行，前后耗时不是严格受控性能对照。

官方56.86秒中文样例在首版细化时：自动仍2标签/9turns，指定4仍4标签/10turns，未解决既有自动欠分；最终版以真实会议对照为验证重点，未重复该无独立标注样例。

## 自动验证与未覆盖项
