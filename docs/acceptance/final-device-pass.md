# 个人记录功能：最后一次真机验收

2026-10-19 用户决定：个人记录（personal context）各步先全部开发、合并，真机验收放在最后统一跑一次。本文收集每一步 PR 留下的真机检查项；跑完后在每项后面写结果（通过 / 失败 + 现象 + 日期），失败项另开工单。

通用前提：iPhone 安装 main 最新构建；有至少两天、带地点的真实录音（录音豆取回或手机录音均可）；千问已配置。

## 需要真机

### 第 5 步：时间线数据（PR「context items」）

- [ ] 用真实录音升级安装后，录音、地点、主题都还在；随后几步的时间线能读到它们（本步本身没有界面）。
- [ ] 杀掉 App 再打开，已纠正的主题关联仍在（第 6 步界面上验证）。

### 第 6 步：今日时间线（#134）

- [ ] 今日页「今日时间线」按发生时间从早到晚列出今天的录音；时间、地点（有的话）、主题都对。
- [ ] 导入一个没有录音时间的文件：显示「时间未知」并排在最后，不显示导入时刻。
- [ ] 点一条进入对应录音并能回听；返回后仍在今日页。
- [ ] 点标签按钮给一条加/去主题，保存后立刻显示；杀掉 App 重开仍在；该录音在「主题」页里的归属不变。

### 第 7 步：承诺 → 待办，导出到提醒事项和日历（#136、#137、#138）

前提：一段真实录音里说过「我明天去买牛奶」「孩子想要相机」「同事说周五发资料」这类话，并已转写。

- [ ] 今日页点「提取待办」：本人承诺进「下一步行动」；愿望、他人承诺只在「全部待办」里分开显示，不计入我的待办。
- [ ] 原话没说具体时刻的显示日期或「时间未定」，不补整点。
- [ ] 待办详情点原话：打开那段录音并从那句话开始播放；返回后详情还在，待办状态不变。
- [ ] 再点一次「提取待办」：不新增重复待办，提示没有新承诺。
- [ ] 另录一段「牛奶买好了」并转写后提取：原待办变已完成；说得含糊的（如「那件事改到下周」）出现在「需要你确认」。
- [ ] 完成 / 重新打开 / 改期 / 取消 / 纠正标题和类型，杀掉 App 重开后仍是改后的样子。
- [ ] 导出到提醒事项：先弹确认框，点「取消」后提醒事项 App 里没有新条目；点「写入」后首次弹系统权限，允许后提醒事项里出现一条，备注里有原话；再点导出不出现第二条。
- [ ] 在提醒事项里勾完成，回到 Koe（切回前台）后待办变已完成；在 Koe 改标题，提醒事项里跟着变。
- [ ] 断网/关权限时在 Koe 改标题、同时在提醒事项改成别的：恢复后详情显示「有冲突」和两个版本，选一个后两边一致。
- [ ] 在提醒事项里删掉条目：Koe 显示已解除关联，待办本身保留。
- [ ] 拒绝提醒事项权限：提示没有权限，Koe 待办照常可用。
- [ ] 导出到日历：没有具体时刻时先让选时间；确认框显示时间和时区；写入后日历里有 1 小时事件；事件时间过去后 Koe 待办不会自动完成；在日历里改时间，Koe 待办时间跟着变；删除事件只解除关联。
- [ ] 提醒只由提醒事项负责：Koe 自己不发通知，不会和提醒事项双响。

### 第 8 步：跨天项目（#135）

- [ ] 项目页不再弹「项目尚未开放」；空列表能直接「新建项目」，填名称和目标后进入项目详情。
- [ ] 详情里「关联资料」勾选不同日子的两段录音，保存后按日期分组显示；点一条能打开原录音回听，返回仍在该项目。
- [ ] 在今日时间线的标签按钮里给一段录音同时勾两个项目：两个项目里都出现它，录音在「资料」里仍只有一份。
- [ ] 把一条待办关联到项目（详情右上角文件夹按钮）：项目「下一步」和项目列表卡片显示它；完成后列表、详情、今日一致。
- [ ] 没有待办的项目显示「尚未形成明确下一步」；项目状态只有手动「标为已完成/归档」才变。
- [ ] 今日页重点卡显示最近有进展的项目，点「打开这个项目」进入详情。
- [ ] 删除项目：录音和待办都还在；杀掉 App 重开，项目与关联保持删除前（或删除后）的真实状态。

### 第 9 步：有来源的日记与本周小结（#140）

- [ ] 今日页「日记 › 今天的日记」：显示纳入几条资料、几条还没有文字；点「生成日记」后出现带【原话】【整理】【建议】标记的内容。
- [ ] 点正文里的 [S1] 之类出处：打开对应录音并从那句开始播放；返回仍在日记页。底部「出处」列表每条也能点。
- [ ] 没有资料的日子显示空态，不生成假正文；断网时生成失败，原来的版本不变。
- [ ] 不加新资料再点：按钮显示「已是最新」，不重复生成。
- [ ] 手动修改后，当天再来一段已转写录音并更新：你的修改仍在，上方提示「已另外生成新稿」，可对照、采用新稿或保留我的。
- [ ] 「本周小结」：周一到周日一份；换到同周另一天打开仍是同一份，重启后不重复生成。
- [ ] 内容不出现资料里没有的情绪、动机。
