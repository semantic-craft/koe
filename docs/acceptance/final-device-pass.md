# 个人记录功能：最后一次真机验收

2026-10-19 用户决定：个人记录（personal context）各步先全部开发、合并，真机验收放在最后统一跑一次。本文收集每一步 PR 留下的真机检查项；跑完后在每项后面写结果（通过 / 失败 + 现象 + 日期），失败项另开工单。

通用前提：iPhone 安装 main 最新构建；有至少两天、带地点的真实录音（录音豆取回或手机录音均可）；千问已配置。

## 需要真机

### 第 5 步：时间线数据（PR「context items」）

- [ ] 用真实录音升级安装后，录音、地点、主题都还在；随后几步的时间线能读到它们（本步本身没有界面）。
- [ ] 杀掉 App 再打开，已纠正的主题关联仍在（第 6 步界面上验证）。

### 第 6 步：今日时间线（#134）

- [ ] 今日页「今日时间线」按发生时间从早到晚列出今天的录音；时间、地点（有的话）、主题都对。
- [ ] 导入一个没有录音时间的文件：显示「时间未知」并排在最后，不显示导入时刻。
- [ ] 点一条进入对应录音并能回听；返回后仍在今日页。
- [ ] 点标签按钮给一条加/去主题，保存后立刻显示；杀掉 App 重开仍在；该录音在「主题」页里的归属不变。

### 第 7 步：承诺 → 待办，导出到提醒事项和日历（#136、#137、#138）

前提：一段真实录音里说过「我明天去买牛奶」「孩子想要相机」「同事说周五发资料」这类话，并已转写。

- [ ] 今日页点「提取待办」：本人承诺进「下一步行动」；愿望、他人承诺只在「全部待办」里分开显示，不计入我的待办。
- [ ] 原话没说具体时刻的显示日期或「时间未定」，不补整点。
- [ ] 待办详情点原话：打开那段录音并从那句话开始播放；返回后详情还在，待办状态不变。
- [ ] 再点一次「提取待办」：不新增重复待办，提示没有新承诺。
- [ ] 另录一段「牛奶买好了」并转写后提取：原待办变已完成；说得含糊的（如「那件事改到下周」）出现在「需要你确认」。
- [ ] 完成 / 重新打开 / 改期 / 取消 / 纠正标题和类型，杀掉 App 重开后仍是改后的样子。
- [ ] 导出到提醒事项：先弹确认框，点「取消」后提醒事项 App 里没有新条目；点「写入」后首次弹系统权限，允许后提醒事项里出现一条，备注里有原话；再点导出不出现第二条。
- [ ] 在提醒事项里勾完成，回到 Koe（切回前台）后待办变已完成；在 Koe 改标题，提醒事项里跟着变。
- [ ] 断网/关权限时在 Koe 改标题、同时在提醒事项改成别的：恢复后详情显示「有冲突」和两个版本，选一个后两边一致。
- [ ] 在提醒事项里删掉条目：Koe 显示已解除关联，待办本身保留。
- [ ] 拒绝提醒事项权限：提示没有权限，Koe 待办照常可用。
- [ ] 导出到日历：没有具体时刻时先让选时间；确认框显示时间和时区；写入后日历里有 1 小时事件；事件时间过去后 Koe 待办不会自动完成；在日历里改时间，Koe 待办时间跟着变；删除事件只解除关联。
- [ ] 提醒只由提醒事项负责：Koe 自己不发通知，不会和提醒事项双响。

### 第 8 步：跨天项目（#135）

- [ ] 项目页不再弹「项目尚未开放」；空列表能直接「新建项目」，填名称和目标后进入项目详情。
- [ ] 详情里「关联资料」勾选不同日子的两段录音，保存后按日期分组显示；点一条能打开原录音回听，返回仍在该项目。
- [ ] 在今日时间线的标签按钮里给一段录音同时勾两个项目：两个项目里都出现它，录音在「资料」里仍只有一份。
- [ ] 把一条待办关联到项目（详情右上角文件夹按钮）：项目「下一步」和项目列表卡片显示它；完成后列表、详情、今日一致。
- [ ] 没有待办的项目显示「尚未形成明确下一步」；项目状态只有手动「标为已完成/归档」才变。
- [ ] 今日页重点卡显示最近有进展的项目，点「打开这个项目」进入详情。
- [ ] 删除项目：录音和待办都还在；杀掉 App 重开，项目与关联保持删除前（或删除后）的真实状态。

### 第 9 步：有来源的日记与本周小结（#140）

- [ ] 今日页「日记 › 今天的日记」：显示纳入几条资料、几条还没有文字；点「生成日记」后出现带【原话】【整理】【建议】标记的内容。
- [ ] 点正文里的 [S1] 之类出处：打开对应录音并从那句开始播放；返回仍在日记页。底部「出处」列表每条也能点。
- [ ] 没有资料的日子显示空态，不生成假正文；断网时生成失败，原来的版本不变。
- [ ] 不加新资料再点：按钮显示「已是最新」，不重复生成。
- [ ] 手动修改后，当天再来一段已转写录音并更新：你的修改仍在，上方提示「已另外生成新稿」，可对照、采用新稿或保留我的。
- [ ] 「本周小结」：周一到周日一份；换到同周另一天打开仍是同一份，重启后不重复生成。
- [ ] 内容不出现资料里没有的情绪、动机。

### 第 10 步：问 Koe（#141）

- [ ] 右下角「问 Koe」进入会话页，不再出现「连续问答尚未开放」；顶部显示范围：几条已转写、几条处理中、几条还没有文字。
- [ ] 问一个资料里有答案的问题：显示「正在查你的资料…」，回答带 [S#] 出处；点出处打开那段录音并从那句开始播放；返回后会话还在。
- [ ] 接着追问（如「那预算呢」）：回答接得上前一个问题。
- [ ] 问资料里没有的事：明确说没有找到，标「无依据」，不编答案（也不调用千问）。
- [ ] 发送后在回答出来前连点发送：只出现一条问题。
- [ ] 断网发送：显示失败和「重试」，问题保留；联网后重试成功，不重复出现问题。
- [ ] 打了一半的问题，去看出处或退出再进：草稿还在。
- [ ] 键盘弹出时消息和发送按钮都能看到、能点。
- [ ] 资料中两处说法矛盾时，回答把两边都列出并各带出处。

### 第 11 步：晨报（今日页）

- [ ] 今日页「晨报」卡：未完成待办数和前三条（逾期/今天到期在前），点一条进待办详情。
- [ ] 他人答应的事到期或已过期的出现在「需要跟进」；未到期的不出现。
- [ ] 打开 App 不自动生成任何要点（千问控制台没有新的调用记录）；点「生成昨天要点」后才生成，每条带出处，点出处回听。
- [ ] 昨天没有资料 / 没转写时显示对应说明，没有生成按钮。
- [ ] 当天再次打开不重复生成；第二天打开是新的一份。

### 第 12 步：导出给外部 AI（Markdown）

- [ ] 今日时间线右上角分享按钮、项目详情菜单「导出给外部 AI」、主题详情的机器人按钮：都弹出预览，写明条数、含原文与出处、地点只到区县。
- [ ] 「复制」后粘贴到外部 AI（如 ChatGPT / 千问网页版）：标题、时间线按时间排序、每句带 [S#]，文末「出处」能对上录音名、时间和录音内位置；按出处在 Koe 里找到同一句并回听一致。
- [ ] 项目导出只含该项目关联的资料和待办；主题导出包含在时间线里手动关联到该主题的录音；当天导出若有日记，日记里的出处编号与时间线一致。
- [ ] 「分享」弹出系统分享面板；取消不报错。
- [ ] 设置里外部 AI / MCP 仍显示「暂未开放」，Koe 不自动向任何外部服务发送资料。

### 第 13 步：手机录音（含自动地点 #139）

- [ ] 任一页「新记录」第一项是「手机录音」；点开后直接开始，首次弹系统麦克风权限，允许后计时走动。
- [ ] 拒绝麦克风权限：面板说明没有权限、可导入音频，点「关闭」回到原页；不生成文件。
- [ ] 录 30 秒以上，中间暂停再继续；锁屏 1 分钟后解锁，计时与录音都没中断。
- [ ] 录音中来电或用 Siri 打断：面板显示「已暂停」，点「继续」接着录。
- [ ] 录音中下滑面板关不掉；「放弃这段录音」先确认，选「继续录音」不受影响，确认放弃后资料里没有它。
- [ ] 「结束并保存」：资料里出现「手机录音 月-日 时:分」，时间是开始录的时刻；能回听，声音完整，时长与计时一致。
- [ ] 允许定位时，几秒后录音信息里出现大致地点并标为自动；拒绝定位时地点为空，可手动填写；取回的录音豆录音不会被填上地点。
- [ ] 保存后可以照常转写、加书签、进今日时间线。
- [ ] 录音中从 App 切换器划掉 Koe，再打开：提示找回了 1 段中断的手机录音，能回听到被划掉前的内容。
- [ ] 录音时正在播放的回听会先停下；录完回听正常、音量正常（不是听筒小声）。

### 第 14 步：自动整理新录音（#133）

前提：千问已配置；资料里已有几条以前的录音。

- [ ] 设置「语音与翻译」里打开「自动整理新录音」：以前的录音不被处理（资料行不出现「待整理/整理中」，千问控制台没有新调用）。
- [ ] 手机录一段说过「我明天去买牛奶」的话并保存：资料行依次显示「转写中 → 整理中 → 已整理」；详情里有文字、默认摘要，今日「下一步行动」出现「买牛奶」。
- [ ] 整理过程中今日页顶部显示「自动整理：N 条整理中」，点它进入资料。
- [ ] 取回一段录音豆录音：取回完整后才开始转写；取回中断时不转写残缺音频。
- [ ] 「整理以前的录音…」：最近 7 天 / 30 天 / 全部显示各自条数；取消不做任何事；选最近 7 天只处理这几天的录音，已有文字的不重新转写。
- [ ] 断网后录一段：资料行显示「整理失败」，详情横幅写明原因；联网后点「重试」完成。
- [ ] 整理中途从 App 切换器划掉 Koe 再打开：已完成的步骤不重做；结果未知的那一步显示「待核实」，不会自己重发；点「确认后重新整理」先弹收费提醒，「先不」不发送，「重新发送」后完成。
- [ ] 手动改过摘要后再校订文字：摘要保持你的版本，不被自动覆盖。
- [ ] 关闭开关：新录音不再自动整理，排队中的也停下。

### 第 15 步：录音豆续录后手机副本跟着变长（#92）

- [ ] 录音豆录 1 分钟后暂停，手机取回并记下时长 A；在录音豆上继续录 1 分钟再停，等手机自动传输（或下拉刷新设备端）：同一条录音被重新取回，时长变为约 A+1 分钟，回听能听到后半段。
- [ ] 重新取回后，已有文字保留，详情提示「音频内容已变化……请手动重新转写」；不会自动重复收费。
- [ ] 杀掉 App 重开：时长仍是新长度，不再反复重新取回同一条。
- [ ] 同一条录音在 Mac 上取回后，两端时长一致（差 1 秒以内）。

## 汇总

第 5–15 步全部合并后，在一台 iPhone 上按顺序跑上面各节；任何一项失败，记下现象、日期和截图位置，另开工单并在此行后注明工单号。
