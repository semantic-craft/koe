## 行为

千问上传前按实际临时上传路径检查大小，测得的音频时长超过 12 小时则拒绝；未知格式时长不伪造。保留原录音路径与任务身份。对于 App 生成的 WAV，仅当同名原始 Opus 时长匹配时选择压缩上传源；无匹配源继续使用原文件。OGG 封装与 multipart 上传分块进行，避免整份文件进入内存。停止等待保留已提交云端任务，后续仍可查询。提交阶段取消不能保证云端取消计费。

录音详情的“摘要与分析”入口使用独立结果存储。摘要和自定义分析分开保存，并记录原文 SHA-256、模型、指令、提示版本、时间、原文依据。使用已配置的千问 Key 和同一服务域名；分析模型为用户确认的 `qwen3.8-flash`，不跟随语音模型。手动触发，不默认自动生成。

长文本按完整 Unicode 字符切块，保留全部字符和来源编号；逐块生成笔记，再分组汇总。已完成节点落盘，失败可重试复用；重启不自动重发结果未知的付费请求。原文变化或取消后的迟到结果不能替换已有结果。生成被截断时不当作成功。结果支持复制、导出、展开原文依据。
