## 真实界面

在 macOS 上构建并运行 `test/support/koe_brand_preview.dart`。此入口复用正式 `KoeApp`
和现有模拟录音控制器，不加载已保存配置、录音或凭据，不连接录音豆。

```sh
flutter build macos --debug --no-pub \
  -t test/support/koe_brand_preview.dart \
  --build-name=1.2.3 --build-number=35
```

实际从桌面侧栏进入设置，打开“关于 Koe”，核对标题、用途、设备型号及
`1.2.3 (35)`。该版本来自本次原生构建参数，不是正式发布版本。
核对关闭操作能够返回设置。截图和 AX 文本见本目录：

- [宽屏关于窗口](about-wide.png)
- [390×844 窄屏组件渲染](koe-about-phone.png)
- [关于窗口的可访问性文本](about-wide-ax.txt)

原生检查发现系统 `AboutDialog` 的默认标题样式在现有主题下不可见；
改为采用现有标题样式的可滚动 `AlertDialog`，再次原生检查确认 Koe 标题可见，
并使用中文“关闭”按钮。没有为此修改全局主题。

截图中的系统窗口名仍为“安克录音豆”，属于 #36 的平台身份改名范围。
本次只确认应用内真实窗口；390 像素窄屏由组件测试验证，不作为 iPhone 真机证据。
