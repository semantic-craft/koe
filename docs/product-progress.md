# 产品进度与剩余验收

2026-10-16 更新；功能基线 main@ecbc4bd。GitHub 总工单 [#6](https://github.com/semantic-craft/koe/issues/6) 跟踪剩余事项；本页区分已交付能力和验证边界。

## 产品目标与当前决定

脱离飞书使用 D3200：独立或 App 发起录音 → 完整取回并保留音频 → 指定服务转写 → 摘要与分析 → 阅读、回听和导出。iPhone、Mac 各自可用。

- 转写保留千问 3.1、豆包极速版及实时二遍；摘要、自定义分析和纪要继续用 Qwen3.8-Flash。摘要手动生成，不默认新增付费任务。
- 不接入豆包标准版；不做双端同步或跨录音问答。两端目前独立保存资料，蓝牙交接不等于资料同步。
- 复用已有约 30 秒授权录音；大小、时长与异常边界用自动化检查。真实长时效果随日常使用观察，不要求专门录长音频。
