怎样并行，哪里要等待

现有对话负责集成即可，无需另开窗口。五批 PR 按 A1 → A2 → A3 → A4 → A5 顺序交付，准备与独立文件实现可以提前并行。

  • A1 期间：并行只读核实系统能力方案、依赖候选与验收场景。
  • A2 接口与依赖确定后：准备四项适配的行为验证；A3 期间可在独立文件准备验收脚本与 A4 实现。
  • A4：转码、朗读、日历、快捷录音可各自分工，汇入一个 PR；快捷录音依赖 A3 明确前台启动约束。
  • Manifest、MainActivity、Gradle、依赖锁文件、控制器接线由同一集成人维护，不并行写入。
  • A5：A1–A4 完成后集中验收。同一 Pixel / D3200 同时只由一个执行者驱动。

开工前先核对已有 Android 工作副本与 PR 归属；不将“有副本”当成“正在开发”，也不假定无人接手。
