# 音频版本与恢复收尾（#10 / #13）

## 当前行为

录音标识不是音频内容版本。完整取回入口对音频分块计算 SHA-256，任务在付费请求前保存 audioHash；改名不改变内容身份。扫描目录和改名不新增付费请求，关闭自动转写或缺少配置仍不提交。

同编号音频变化时，保留原文字、分析和云端任务，提示手动重新转写，不自动重复收费。摘要/纪要/导图标记旧内容；重新转写成功前不允许继续对旧文本生成新分析。已取得任务 ID 或已保存待落盘结果时，音频不匹配就停止恢复并保留任务；恢复原文件后可继续原任务。请求返回后再次核对音频，变化时不保存迟到结果。

新任务持久化内容身份；旧任务没有 digest 时，只建立当前文件基线，不追溯宣称历史音频相同，不重做收费任务。没有旧副本时无法重建历史音频。重复取回、重启与原任务查询不自动切换供应商或重提未知请求。摘要继续手动生成，分段检查点复用现有 #24 机制。

## 回退测试

- “retrieved changed audio keeps old result and requires explicit retry”在旧代码失败于没有内容变化提示；修复后保持一次调用、原文字不变，手动重试后恢复。
- “changed audio during request cannot overwrite existing transcription”在旧代码失败于旧文字被迟到结果覆盖；修复后保留原成功结果。
- 新增同尺寸/同修改时间内容变化、改名内容不变、缺失文件、已提交任务音频不符不发请求/保留任务 ID/恢复原音频后继续、旧分析失效且禁止新付费生成。
- 保留既有排队/已提交/未知/结果恢复、存储失败阻止请求、摘要检查点复用及迟到响应测试。取消 Apple 文件工作测试改为等待实际服务进入后再开始录音，不依赖单次事件循环时序。
- 集成最新 Koe 命名主线后全量 291 项通过，静态分析通过。iPhone 与 Mac Release 构建通过，iPhone 候选版已安装。回归日志见 build/device-validation/source-final-tests.log。

## 没跑到的项目

不专门录长音频；长时性能与服务效果随使用观察。内容版本检查不是音频格式解析或语义比对，不改变已有上传源匹配规则。真实 Wi-Fi SoftAP、人工逐字准确率/试听、VoiceOver 及系统电量等未由自动化代替，分开记录于 #15/#16。
