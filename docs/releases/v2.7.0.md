# Koe 2.7.0（构建 16）

这是 Koe 在公开仓库 `semantic-craft/koe` 的 `2.7.0` GitHub Release。本次版本将 macOS、Android 与 iOS 三端同步至 `2.7.0`（构建 `16`），交付 iOS 与 Android 原生客户端全功能齐平（Phase 0–3E + M1–M10）、双端轻量九旅程 E2E 闭环以及 iOS 1024×1024 应用图标资产目录。

## 主要变化

1. **iOS 原生客户端全功能齐平与后台能力**（[#776](https://github.com/semantic-craft/koe/pull/776)、[#786](https://github.com/semantic-craft/koe/pull/786)–[#790](https://github.com/semantic-craft/koe/pull/790)、[#792](https://github.com/semantic-craft/koe/pull/792)–[#793](https://github.com/semantic-craft/koe/pull/793)、[#795](https://github.com/semantic-craft/koe/pull/795)–[#797](https://github.com/semantic-craft/koe/pull/797)）：
   - **共享核心与原生适配层**：拆出零 UI 依赖的 `KoeAppleCore`，落地 4 Hz 宿主轮询与可编辑模型设置、`AVAudioSession` / `AVAudioEngine` 麦克风采集与输入路由监控、`AVPlayer` 分段回放、共享 D3200 CoreBluetooth 适配器，以及安全作用域文件导入和单条/当日/批量 Markdown 导出。
   - **工作区齐平与后台恢复**：补齐随心闪记、全天听记、实时纪要三模式完整工作区、录音输入源选择面板、记录编辑/行动/问答闭环、全局常驻录音与播放控制及 iPad 分栏自适应；新增 CoreBluetooth 后台状态恢复与锁屏/控制中心播放控制。
   - **打包资产与版本锁步**：新增 1024×1024 不透明单尺寸通用 `Assets.xcassets/AppIcon.appiconset` 资产目录，并将 `MARKETING_VERSION`、`CURRENT_PROJECT_VERSION` 与 `AppIcon.png` 纳入仓库锁步检查。
2. **Android 原生客户端全功能齐平与 D3200 豆控**（[#773](https://github.com/semantic-craft/koe/pull/773)–[#774](https://github.com/semantic-craft/koe/pull/774)、[#778](https://github.com/semantic-craft/koe/pull/778)、[#780](https://github.com/semantic-craft/koe/pull/780)–[#784](https://github.com/semantic-craft/koe/pull/784)、[#792](https://github.com/semantic-craft/koe/pull/792)、[#794](https://github.com/semantic-craft/koe/pull/794)、[#798](https://github.com/semantic-craft/koe/pull/798)–[#799](https://github.com/semantic-craft/koe/pull/799)）：
   - **跨平台原生底座与适配层**：落地 Rust C++17 JNI 桥接与 16 KB 页大小对齐、Gradle Compose M3 + `StateFlow` 宿主切片、`AudioRecord` + `AudioFocus` + 前台服务采集、分段 `TimelineWavReader` + `AudioTrack` 回放、D3200 BLE GATT 串行写入队列（API 29–36）以及 SAF `content://` 文件导入和 Markdown 导出。
   - **工作区齐平与系统体验**：补齐三模式完整工作区、录音输入源选择面板、记录编辑/行动/问答闭环与平板横屏自适应；支持 D3200 录音中暂停/续录与前台通知栏豆控、系统返回与软键盘避让、删除防误删确认以及 `github` / `play` 双分发渠道配置。
3. **双端轻量验证底座与九旅程 E2E 闭环**（[#800](https://github.com/semantic-craft/koe/pull/800)、[#801](https://github.com/semantic-craft/koe/pull/801)）：
   - 落地 `simslim`（iOS）与 `avdslim`（Android）轻量验证底座、九旅程模块化 Maestro 用例与四维取证校验器 `scripts/verify_mobile_e2e.py`，并修复实测暴露的窄屏采集条、详情头部换行、编辑弹层高度与回收站交互缺陷。
4. **macOS 界面优化与开源仓库加固**（[#767](https://github.com/semantic-craft/koe/pull/767)、[#768](https://github.com/semantic-craft/koe/pull/768)、[#770](https://github.com/semantic-craft/koe/pull/770)、[#772](https://github.com/semantic-craft/koe/pull/772)）：
   - 重构「所有记录」管理台并移除顶栏多余「新建记录」按钮；完成开源安全加固、MIT `LICENSE` 补充与托管 `macos-26` CI 切换；修复 Python `F_GETPATH` 1024 字节缓冲兼容并统一密钥工作流至 `.secrets` + `with-secrets`。

## 验收边界

- **已通过自动化与模拟/仿真器门禁**：全量 `./scripts/check`（Rust workspace、Clippy、Python 契约测试与三端版本/构建号锁步、UI 规范门禁、macOS SwiftPM 与 Android JVM JNI 测试）、Android Gradle 单元测试（`testGithubDebugUnitTest`）、iOS Simulator 构建、远端 CI，以及基于 `simslim` 与 `avdslim` 的双端九旅程 E2E 闭环校验均已通过。
- **物理真机验收边界**：模拟/仿真器 E2E 不等同于物理设备硬件验收。物理 iPhone / iPad 签装、Keychain 升级保留、实机 CoreBluetooth 后台唤醒、锁屏/耳机媒控与实体 Soundcore Work（D3200）验收继续追踪在 [#775](https://github.com/semantic-craft/koe/issues/775)；物理 Android 15/16（16 KB 页大小）与 API 29–30 签装、Android Keystore 凭据保留、实体 D3200 BLE 与前台通知豆控验收继续追踪在 [#777](https://github.com/semantic-craft/koe/issues/777)。

## 下载与安装

### macOS（`Koe-2.7.0-macos-arm64.zip`）

面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压 `Koe-2.7.0-macos-arm64.zip` 后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包沿用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。

### Android（`Koe-2.7.0-android-arm64.apk`）

面向 `arm64-v8a` 设备，最低 Android 10（API 29），目标 SDK 为 Android 16（API 36）并满足 16 KB 页大小对齐要求。Release 附件为 `github` 渠道签名的 `Koe-2.7.0-android-arm64.apk`（包名 `com.semanticcraft.koe`），可在设备上直接安装（需允许从浏览器或文件管理器安装未知来源应用），或通过 `adb install -r Koe-2.7.0-android-arm64.apk` 安装覆盖。

### iOS（TestFlight / 直接安装）

面向 iOS 17.0 及以上的 iPhone 与 iPad（Bundle ID `com.semanticcraft.koe.ios`）。公开分发通过 TestFlight 链接安装（构建 `16` 发布后将在 Release 说明中附上邀请链接）。如需从源码直接签装到真机，先执行 `./platforms/ios/build-native.sh device` 与 `xcodegen generate --spec platforms/ios/project.yml`，再用 Xcode 打开 `platforms/ios/KoeiOS.xcodeproj` 并指定你自己的 Apple Developer 团队（`DEVELOPMENT_TEAM`）编译安装。
