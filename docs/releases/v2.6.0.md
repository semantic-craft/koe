# Koe 2.6.0（构建 15）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.6.0` GitHub Release，正式落地「Qwen 主力语音识别 + DeepSeek 4.1 Flash 默认文本整理」模型分工架构，并补齐旧工作区无损自动迁移、双槽凭据隔离加固与双密钥启动转发。仓库与发行附件保持私有。

## 主要变化

1. **默认文本模型切换为 DeepSeek 4.1 Flash，Qwen 专注主力 ASR**（[#763](https://github.com/semantic-craft/koe/pull/763)）：
   - **LLM 文本整理与问答**：`DEFAULT_TEXT_MODEL` 升级为 `deepseek-flash`（DeepSeek 4.1 Flash），`LlmProvider` 收口为 `DeepSeek | Custom`（提供默认推荐 `deepseek-flash`、旗舰推理 `deepseek-v4-pro` 及自定义兼容接口），移除 Qwen LLM 选项与 `ThinkingMode::Qwen`，深度思考开关统一使用 DeepSeek `thinking: {"type": "enabled" | "disabled"}`。
   - **ASR 语音识别**：以阿里云百炼 Qwen-Audio 3.1 系列为主力（默认实时流式 `qwen-audio-3.1-asr-flash-streaming`，可选 `-message` / `-flash` / `-filetrans`），同时保留 DeepSeek 官方 `POST /v1/tools/asr` 作为次选 ASR（超 120s 自动静音切片顺序拼接）。
   - **模型设置界面**：快捷组合收敛为「Qwen 语音 + DeepSeek 文本（推荐）」与「DeepSeek 官方全套」；凭证卡片明确区分 Qwen（主力 ASR）与 DeepSeek（默认 LLM + 次选 ASR），`qwenWorkspaceId` 仅作用于 Qwen ASR 端点。
2. **旧工作区无损自动迁移与双槽凭据隔离**（[#763](https://github.com/semantic-craft/koe/pull/763)）：
   - 打开旧版（如 `v2.5.0` 或更早）使用 Qwen LLM 或空白 `llm_provider` + DashScope 对话地址的工作区时，自动迁移至 `llm_provider = "deepseek"`、`model = "deepseek-flash"`、`chat_endpoint = "https://api.deepseek.com/chat/completions"`，同时完整保留既有的 Qwen ASR 配置、业务空间 ID 与 Qwen 钥匙串凭据。
   - 新增 `CredentialStore::prepare_for_slot` 槽位透传与 `NativeCredentials` 首尾空白裁剪，彻底杜绝环境隔离模式下双槽串用或带空白密钥失败；`scripts/run-with-secrets.py` 新增 `DEEPSEEK_API_KEY` 白名单转发及黑盒契约测试。

## 下载与安装

`Koe-2.6.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。
