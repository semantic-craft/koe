# Koe 2.0.0（构建 9）

这是 Koe 在当前私有仓库的首个 GitHub Release，与 Responsay 的配套版本一起交付。仓库和下载附件保持私有。

## 当前可用

- 首页提供随心闪记、全天听记、实时纪要和语音输入的模式入口。
- 普通录音键默认随心闪记。其他采集模式由 macOS 入口显式开启，本次会话授权不变成重启后自动录音。
- 语音输入入口准备录音豆待命并打开 Responsay，沿用已有音源 socket 配置。
- 现有录音、转写、记录详情、问 Koe、待办与记忆继续使用同一 Rust 工作区。

## 当前边界

四模式的完整业务页面仍处于交互稿阶段，见[四模式工作区](../mode-workspaces.md)。本次发布交付已有模式入口和当前应用实现。

Koe 到 Responsay 的真实 PCM 收音和软件起止已有部分证据。真实 Responsay ASR、原光标输入、实体双击、断连恢复、三种输入快捷键及无重复录音或识别仍未验收，继续跟踪 [Responsay #810](https://github.com/semantic-craft/responsay-macos/issues/810) 和 [#822](https://github.com/semantic-craft/responsay-macos/issues/822)。软件回放通过不代表物理按键或识别上屏通过。

全天长时硬件验收继续跟踪 [Koe #662](https://github.com/semantic-craft/koe/issues/662)。已有记录、用户配置、系统权限和音源 socket 保留。语音输入目前仍可保存记录，不承诺设备或 Koe 不留录音。

## 下载与安装

`Koe-2.0.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14。Apple 本机识别需要 macOS 26 或更高版本。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

签名包使用现有 Developer ID 与 Bundle ID。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检、公证及本机升级验证以 Release 附带的验收回执为准，独立硬件验收不作为本次代码发布的完成声明。
