# Koe 2.7.1（构建 17）

这是 Koe 在公开仓库 `semantic-craft/koe` 的 `2.7.1` 补丁 GitHub Release。本次版本将 macOS、Android 与 iOS 三端版本号与构建号同步升级至 `2.7.1`（构建 `17`），将 Android 启动图标统一为官方 Koe 自适应图标及 Material You 单色层，并将三端图标生成与契约校验纳入统一脚本与门禁。

## 主要变化

1. **Android 官方自适应启动图标与 Material You 单色层统一**（[#806](https://github.com/semantic-craft/koe/pull/806)）：
   - 以仓库官方原图 `assets/artwork/koe-schoolgirl-b-cheerful.png` 替换原 M3 黑白波形占位矢量，使 Android、macOS 与 iOS 三端应用图标保持一致。
   - 生成 `mdpi`（108 px）至 `xxxhdpi`（432 px）五套密度的 8/9 居中前景 PNG（`ic_launcher_foreground.png`）与基于 Rec.709 亮度映射的 Material You 主题单色层（`ic_launcher_monochrome.png`），配套 `#FFD9BB` 底色（`values/colors.xml`）及 `mipmap-anydpi-v26/ic_launcher.xml`、`ic_launcher_round.xml` 三层配置，并移除过时的 `drawable/ic_launcher_foreground.xml` 与 `drawable/ic_launcher_background.xml`。
2. **三端统一图标生成脚本与跨平台契约门禁**（[#806](https://github.com/semantic-craft/koe/pull/806)）：
   - 扩展 `scripts/generate-app-icons.swift` 为单一生成入口，直接从同一官方原图输出 macOS、iOS 与 Android 三端图标资产。
   - 在 `scripts/test_install_macos.py` 新增 Android 官方自适应图标契约门禁（校验五密度 PNG 尺寸与 8-bit RGBA 格式、`#FFD9BB` 底色、`adaptive-icon` 三层引用及旧占位矢量清理），与三端版本/构建号锁步测试及 iOS `AppIcon` 门禁共同守护发版一致性。

## 验收边界

- **已通过自动化门禁**：全量 `./scripts/check`（Rust workspace、Clippy、Python 契约与三端版本/构建号/图标锁步测试、UI 规范门禁、macOS SwiftPM 与 Android JVM JNI 测试）、`./scripts/install-macos.sh --dump-info-plist`（确认 `2.7.1` / `17`）、`python3 scripts/test_install_macos.py`（13/13），以及 Android Gradle 单元测试（`testGithubDebugUnitTest`）与 Release Lint（`lintGithubRelease`）均已通过。
- **物理真机验收边界**：自动化测试、Lint 与模拟/仿真器 E2E 不等同于物理设备硬件验收。物理 iPhone / iPad 签装、Keychain 升级保留、实机 CoreBluetooth 后台唤醒、锁屏/耳机媒控与实体 Soundcore Work（D3200）验收继续追踪在 [#775](https://github.com/semantic-craft/koe/issues/775)；物理 Android 15/16（16 KB 页大小）与 API 29–30 签装、Android Keystore 凭据保留、实体 D3200 BLE 与前台通知豆控验收继续追踪在 [#777](https://github.com/semantic-craft/koe/issues/777)。

## 下载与安装

### macOS（`Koe-2.7.1-macos-arm64.zip`）

面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压 `Koe-2.7.1-macos-arm64.zip` 后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包沿用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。

### Android（`Koe-2.7.1-android-arm64.apk`）

面向 `arm64-v8a` 设备，最低 Android 10（API 29），目标 SDK 为 Android 16（API 36）并满足 16 KB 页大小对齐要求。Release 附件为 `github` 渠道签名的 `Koe-2.7.1-android-arm64.apk`（包名 `com.semanticcraft.koe`），可在设备上直接安装（需允许从浏览器或文件管理器安装未知来源应用），或通过 `adb install -r Koe-2.7.1-android-arm64.apk` 安装覆盖。

### iOS（TestFlight Build `17` / 直接安装）

面向 iOS 17.0 及以上的 iPhone 与 iPad（Bundle ID `com.semanticcraft.koe.ios`）。公开分发通过 TestFlight 安装（构建 `17` 发布后将在 Release 说明中附上邀请链接）。如需从源码直接签装到真机，先执行 `./platforms/ios/build-native.sh device` 与 `xcodegen generate --spec platforms/ios/project.yml`，再用 Xcode 打开 `platforms/ios/KoeiOS.xcodeproj` 并指定你自己的 Apple Developer 团队（`DEVELOPMENT_TEAM`）编译安装。
