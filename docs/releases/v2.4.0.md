# Koe 2.4.0（构建 13）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.4.0` GitHub Release，全栈交付应用版本号展示、原生关于/菜单版本入口与按需手动软件更新检查。仓库与发行附件保持私有。

## 主要变化

1. **版本元信息与跨层锁步契约**（[#753](https://github.com/semantic-craft/koe/pull/753)）：
   - 在 `koe-engine` 新增 `version.rs`，提供严格 `MAJOR.MINOR.PATCH` 语义化版本解析比较、`validate_build_number` 构建号校验与官方 GitHub Releases 常量。
   - 在 `scripts/test_install_macos.py` 新增跨层锁步契约测试，确保 `Cargo.toml`、`crates/koe-engine`、`AppUpdateSnapshot` 与 `scripts/install-macos.sh` `Info.plist` 版本号及构建号一致。
2. **后台更新检查通道与运行时编排**（[#753](https://github.com/semantic-craft/koe/pull/753)）：
   - 在 `koe-client-providers` 的 `ProviderPool` 扩展独立第 4 车道 `ProviderLane::Update` 与 `network/update.rs`，实现无凭据 GitHub Releases 查询（`512 KiB` 流式体积上限、至多 3 跳同信任边界重定向校验与按架构优先匹配安装包）。
   - 在 `koe-runtime` 新增 `app_update.rs` 维护 `AppUpdateState`、幂等元数据同步、退出排空期即时取消在途更新请求与升级后自动清理旧通知；`koe-cli` 新增免工作区 `koe version` / `--version` / `-V` 并在 `doctor` / `status` 展示版本与更新状态。
3. **原生 macOS 版本展示与手动更新检查界面**（[#753](https://github.com/semantic-craft/koe/pull/753)）：
   - 左侧边栏顶部展示版本标签及悬停提示，系统应用菜单「关于 Koe」与状态栏/Dock 菜单统一展示 `v2.4.0 (13)`。
   - 设置页首屏置顶「版本与软件更新」卡片，支持从应用菜单、状态栏菜单与设置页手动触发检查更新，私有仓库状态下返回清晰的未公开提示并提供官方发行页外链跳转。

## 验收边界

- `2.4.0` 全量本地门禁（`./scripts/check`：Python 契约测试、`verify-ui-principles.py`、`check_swiftui_perf.py`、`check_notary_policy.py`、`progress.py check`、`cargo clippy`、`cargo test --workspace`、`swift test`）均已通过；签名安装版与公证包验收结果见 Release 验收回执与 [#752](https://github.com/semantic-craft/koe/issues/752)。
- 移动端与远期需求（[#124](https://github.com/semantic-craft/koe/issues/124)、[#149](https://github.com/semantic-craft/koe/issues/149) 至 [#155](https://github.com/semantic-craft/koe/issues/155) 及 [#14](https://github.com/semantic-craft/koe/issues/14)）属下一阶段范围，不计入本次 macOS 2.4.0 完成声明。

## 下载与安装

`Koe-2.4.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。
