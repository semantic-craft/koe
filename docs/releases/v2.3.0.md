# Koe 2.3.0（构建 12）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.3.0` GitHub Release，整合五轮四层架构去胶水清理、后台云端车道隔离、二进制 C ABI 统一、Swift 6 严格并发清零与规范化 Apple 公证打包脚本。仓库与发行附件保持私有。

## 主要变化

1. **四层边界拉直与二进制 C ABI 收口**（[#740](https://github.com/semantic-craft/koe/pull/740)）：
   - 将纯计算 `hash` / `prng` 原语收回 `koe-engine`，消除其对 `koe-client-base` 的反向依赖及 `koe-client-providers` 重复 `sha2` 依赖，并清理 `koe-host-api` / `koe-cli` 多余 crate 依赖。
   - 拆分 `HostIntent` / `AdapterEvent`，新增 `KoeOwnedBytes` 二进制 C ABI 传输 BLE TX 帧与 Local ASR PCM，淘汰弱类型回调与全部 4 条 `NotificationCenter` 字符串总线，抽离 `KoeWindowPresenter` 并加固 `verify-ui-principles.py` 门禁。
2. **后台多车道并发、去影子索引与统一导出**（[#742](https://github.com/semantic-craft/koe/pull/742)、[#748](https://github.com/semantic-craft/koe/pull/748)）：
   - 以按车道隔离的 `ProviderPool` 彻底取代单槽阻塞的 `ProviderWorker`，长耗时问答不再阻塞批处理补转写与实时纪要，并取消阻塞主线程的同步 `thread.join()`。
   - 移除 `captures.records_by_file_id` 影子索引、未消费顶层快照字段及旧 `export_record`，导出统一收口到原文优先 `export_workspace_markdown`。
3. **单体模块拆分、热路径优化与 Swift 6 严格并发清零**（[#744](https://github.com/semantic-craft/koe/pull/744)、[#745](https://github.com/semantic-craft/koe/pull/745)、[#748](https://github.com/semantic-craft/koe/pull/748)）：
   - 将 `koe-engine`（`context`、`minutes`、`session`）与 `koe-runtime`（`mcp_surface`、`speech`、`dispatch`）超大单文件拆分为职责内聚的子模块。
   - 新增 `HostSection` 统一侧边栏、菜单与页面标题/图标元信息，全仓消除弱类型 `HostSessionStore.send(_:)`，清零 `KoeAppleShared` 与 `KoeMacHost` 的 Swift 6 `-strict-concurrency=complete` 警告。
   - 用强类型 `LifecycleState` 替代每 250ms `poll_timers` / `ingest_ble_chunk` 的双次 JSON 堆分配比较，并将 `quick_note_workspace_json` 改为 $O(I + R)$ 预索引投影。
4. **移除独立语音输入模块并统一发布入口**（[#738](https://github.com/semantic-craft/koe/pull/738)、[#739](https://github.com/semantic-craft/koe/pull/739)）：
   - 移除不再使用的语音输入模块与伴侣桥接；新增 `scripts/release-macos.sh` 统一 `--options runtime --timestamp` 签名、`--verify-self` / `--smoke-test`、`xw-notary` 公证与校验和生成。

## 验收边界

- `2.3.0` 全量本地门禁（`./scripts/verify-local.sh`、Swift 6 `-strict-concurrency=complete`）及物理 `Studio Display Microphone`（48 kHz）、macOS 26 `SpeechAnalyzer` 中文流式识别、`KoeWindowPresenter` 关闭/最小化唤醒与真机 D3200（`soundcore Work`）离线拉取均已通过；人工确认工单（[#722](https://github.com/semantic-craft/koe/issues/722)、[#725](https://github.com/semantic-craft/koe/issues/725)、[#731](https://github.com/semantic-craft/koe/issues/731)、[#741](https://github.com/semantic-craft/koe/issues/741)、[#743](https://github.com/semantic-craft/koe/issues/743)、[#746](https://github.com/semantic-craft/koe/issues/746)、[#747](https://github.com/semantic-craft/koe/issues/747)）已按要求收口关闭。
- 移动端与远期需求（[#124](https://github.com/semantic-craft/koe/issues/124)、[#149](https://github.com/semantic-craft/koe/issues/149) 至 [#155](https://github.com/semantic-craft/koe/issues/155) 及 [#14](https://github.com/semantic-craft/koe/issues/14)）属下一阶段范围，不计入本次 macOS 2.3.0 完成声明。

## 下载与安装

`Koe-2.3.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。
