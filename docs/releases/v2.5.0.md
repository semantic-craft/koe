# Koe 2.5.0（构建 14）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.5.0` GitHub Release，全栈交付重构后的「模型设置」（阿里云百炼 Qwen 最新版与 DeepSeek 官方 ASR/LLM）、独立顶级「录音管理」页面、侧栏底栏录音豆常驻状态弹层与侧栏顶部版本胶囊更新弹层。仓库与发行附件保持私有。

## 主要变化

1. **「模型设置」重构与 Qwen / DeepSeek 官方最新模型接入**（[#758](https://github.com/semantic-craft/koe/pull/758)）：
   - 原「设置」更名收口为「模型设置」，支持阿里云百炼（Qwen）与 DeepSeek 官方双钥匙串独立凭证、一键快捷组合与跨服务商自由混搭，并支持自定义 OpenAI 兼容或本机 localhost 服务。
   - **ASR 语音识别**：升级为 Qwen-Audio 3.1 四款最新模型——默认实时流式 `qwen-audio-3.1-asr-flash-streaming`、实时短段润色 `qwen-audio-3.1-asr-flash-message`、HTTP 同步 `qwen-audio-3.1-asr-flash` 与异步长录音 `qwen-audio-3.1-asr-flash-filetrans`（后两者支持说话人分离与 OSS 临时上传）；新增 DeepSeek 官方 `POST /v1/tools/asr`（单次 ≤120s，客户端对超长录音按静音点自动切片 ≤110s 逐段拼接），非实时云端 ASR 停录后自动排入后台批转写并保持系统防休眠。
   - **LLM 文本整理与问答**：升级为 Qwen 最新版（默认 `qwen3.7-plus` 替代旧版 `qwen-plus`，可选旗舰 `qwen4-max` 与极速 `qwen3.8-flash`，支持填写业务空间 ID 切换 `{WorkspaceId}.cn-beijing.maas.aliyuncs.com` 专属域名）及 DeepSeek 官方最新版（默认 `deepseek-flash`、旗舰 `deepseek-v4-pro`），支持双服务商深度思考开关（`enable_thinking` / `thinking`）。
2. **独立顶级「录音管理」页面**（[#758](https://github.com/semantic-craft/koe/pull/758)）：
   - 在侧栏「音频与模型」分组下拆出独立「录音管理」页面，集中编排录音豆与 Mac 麦克风音源选择、自动优先策略、「同时采集系统音频」（选录音豆自动禁用）、录音豆离线文件列表与取回，以及本机音频目录占用统计与「在访达中显示」。
3. **录音豆状态弹层与版本胶囊更新弹层脱离设置**（[#758](https://github.com/semantic-craft/koe/pull/758)）：
   - 录音豆连接状态、麦克风/充电仓双电量、设备存储、固件版本、Mac/手机蓝牙控制权与自动重连移至侧栏底部常驻状态胶囊 + 原生 macOS Popover。
   - 原设置页软件更新卡片收口至侧栏顶部 `v2.5.0` 胶囊弹层，点击菜单栏「检查更新…」直接弹出该弹层而不强切页面。

## 下载与安装

`Koe-2.5.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及公证记录以 Release 附带的验收回执为准。
