# Koe 2.1.0（构建 10）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.1.0` GitHub Release，完整交付 macOS 2.x 桌面功能集、跨四层架构收敛与 SwiftUI 及 FFI 性能重构。仓库与发行附件保持私有。

## 当前可用

1. 正式四大业务工作区与二级导航：「随心闪记、全天听记、实时纪要、语音输入」完整业务页、「所有记录」六类筛选与搜索、自定义 Markdown 导出，以及首页音源状态胶囊、动态操作短句与一键「切换为录音豆」（[#712](https://github.com/semantic-craft/koe/pull/712)、[#721](https://github.com/semantic-craft/koe/pull/721)）。
2. Mac 系统音频双路采集：`CATapDescription` 系统声音与麦克风共同时间轴录制、`-100 dBFS` Barker-13 权限静音探针及单路失败保留（[#715](https://github.com/semantic-craft/koe/pull/715)）。
3. 可靠性与界面一致性加固：两阶段 Keychain 凭据登记与提交前崩溃孤儿项精确回收（[#714](https://github.com/semantic-craft/koe/pull/714)）、断连录音豆残片挽救与语音输入 Socket 事件排空（[#704](https://github.com/semantic-craft/koe/pull/704)）、弹窗与退出面板浅色表面锁定（[#702](https://github.com/semantic-craft/koe/pull/702)）。
4. 跨四层架构收敛：统一 `WorkspaceSelection` 会话分离清理、定向 MCP 切片投影与强类型 Swift `HostCommand`（[#695](https://github.com/semantic-craft/koe/pull/695)、[#697](https://github.com/semantic-craft/koe/pull/697)、[#708](https://github.com/semantic-craft/koe/pull/708)、[#724](https://github.com/semantic-craft/koe/pull/724)）。
5. 宿主观测与音频管线性能重构：`HostSessionStore` 分域 `@Observable` 切片、4 Hz 叶子栏静态门禁、二进制 PCM C ABI 快路径、批量排空、关窗及最小化离屏 `NSHostingView` 重排门控（关窗后台播放耗时降 `1314.5x`，双路采集 CPU 降 `81.15%`）及 CoreAudio HAL 事件监听（[#726](https://github.com/semantic-craft/koe/pull/726)）。
6. 双语产品与 D3200 硬件协议文档重写（[#720](https://github.com/semantic-craft/koe/pull/720)）。

## 当前边界

代码实现与全量自动门禁已全部完成。两项非阻塞物理硬件核对以 `ready-for-human` 独立工单继续跟踪：[#722](https://github.com/semantic-craft/koe/issues/722)（首页音源条与录音豆一键切换实机核对）与 [#725](https://github.com/semantic-craft/koe/issues/725)（离屏关窗录音豆实体按键唤醒与外接耳机热插拔核对）。Responsay 侧物理快捷键继续跟踪 [Responsay #822](https://github.com/semantic-craft/responsay-macos/issues/822)。

移动端与双端同步（[#124](https://github.com/semantic-craft/koe/issues/124)、[#149](https://github.com/semantic-craft/koe/issues/149) 至 [#155](https://github.com/semantic-craft/koe/issues/155)）及 [#14](https://github.com/semantic-craft/koe/issues/14) 属下一阶段范围，不计入本次 macOS 2.1.0 完成声明。

## 下载与安装

`Koe-2.1.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检、公证及本机升级验证以 Release 附带的验收回执为准。
