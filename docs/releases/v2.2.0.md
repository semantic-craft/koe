# Koe 2.2.0（构建 11）

这是 Koe 在私有仓库 `semantic-craft/koe` 的 `2.2.0` GitHub Release，整合 Mac 到手机蓝牙控制权切换、Responsay 历史租约与跨应用胶水清理，以及对标外部 Rust、FFI、SwiftUI 与 CoreAudio/CoreBluetooth 工程指南的全栈可靠性加固。仓库与发行附件保持私有。

## 当前可用

1. Mac 到手机蓝牙控制权切换与四端一致守门（[#732](https://github.com/semantic-craft/koe/pull/732)）：
   - 首页「模式选择」音源条新增「Mac 使用 / 手机接管」分段开关（补齐键盘焦点环与 28pt 热区），录音管理、设置页与顶部状态栏菜单统一由 `HostCommand.deviceRelease` 与 `canReleaseToPhone` 驱动。
   - Rust 边界在 `Command::DeviceRelease` 与 `Command::SetBleAutoConnect { enabled: false }` 统一拦截离线拉取、暂停拉取及设备录音中状态，并由 `BluetoothBridge.syncWithRuntimeDevice` 协同释放链路。
2. 本地桥接收敛与死胶水清理（[#733](https://github.com/semantic-craft/koe/pull/733)、[#732](https://github.com/semantic-craft/koe/pull/732)）：
   - 移除 Responsay 专属 `external_pcm_v1` 租约、`open_responsay` 跨应用拉起动作以及跨四层的 `HostAction` / `drain_host_actions_json` 空壳管道，保留通用 `koe.sock` `companion/subscribe` 实时事件与听写定稿接口。
3. Rust FFI、SwiftUI 与音视频实时线程全栈加固（[#734](https://github.com/semantic-craft/koe/pull/734)）：
   - 消除 `koe-engine`、`koe-runtime` 与 `koe-client-providers` 生产路径中的可达 `.unwrap()` / `.expect()`；`koe-host-api` 在加锁前校验 `ingest_pcm` 边界，将 `SubscriberHub.broadcast` 移出全局 `sessions()` 锁，并恢复锁中毒状态。
   - 消除 SwiftUI 实时纪要与记录详情中的 4 处 `ForEach(..., id: \.offset)`；`BluetoothBridge` 借助 `queue: .main` 改为严格 FIFO 的 `MainActor.assumeIsolated` 派发；`AudioCallbackFence` 与 `MicrophoneMailbox` 改用 `OSAllocatedUnfairLock` 与固定容量预分配环形队列；`verify-ui-principles.py` 扩展至扫描 `KoeAppDelegate` 与 `KoeWindowPresenter`。

## 当前边界

代码实现与全量自动门禁已全部完成。物理硬件实机核对继续以 `ready-for-human` 独立工单跟踪：[#722](https://github.com/semantic-craft/koe/issues/722)（首页音源条切换）、[#725](https://github.com/semantic-craft/koe/issues/725)（离屏唤醒与耳机热插拔）与 [#731](https://github.com/semantic-craft/koe/issues/731)（Mac 到手机控制权切换与 iPhone 飞书妙记接管）。

移动端与双端同步（[#124](https://github.com/semantic-craft/koe/issues/124)、[#149](https://github.com/semantic-craft/koe/issues/149) 至 [#155](https://github.com/semantic-craft/koe/issues/155)）及 [#14](https://github.com/semantic-craft/koe/issues/14) 属下一阶段范围，不计入本次 macOS 2.2.0 完成声明。

## 下载与安装

`Koe-2.2.0-macos-arm64.zip` 面向 Apple silicon Mac，最低 macOS 14（系统音频双路采集需 macOS 14.2 及以上，Apple 本机识别需 macOS 26 及以上）。下载并解压后，将 `Koe.app` 放入 `/Applications`，替换前退出正在运行的 Koe。

安装包使用既有 Developer ID 与 Bundle ID（`com.anker.ankerRecorder`），保留既有记录、配置、Keychain 凭据、系统权限与 `koe.sock`。第三方说明及许可证位于 `Koe.app/Contents/Resources/Licenses/`。签名、自检及本机升级验证以 Release 附带的验收回执为准。
